# 🛡️ GTN VPN — Telegram-бот для Marzban

[![CI](https://github.com/emel1ch/tg_vpn/actions/workflows/ci.yml/badge.svg)](https://github.com/emel1ch/tg_vpn/actions/workflows/ci.yml)

Асинхронный Telegram-бот на **aiogram 3** для управления VPN-подписками через панель **[Marzban](https://github.com/Gozargah/Marzban)** (Xray-core). Полный цикл: регистрация → триал → оплата (СБП / крипта) → выдача доступа → напоминания об истечении → продление. Плюс встроенная админ-панель для управления сервером и пользователями прямо из Telegram.

Продовый проект — все изменения вносятся обратно совместимо с текущей БД (миграции через `ALTER TABLE`, без дропа данных).

## ✨ Возможности

### 👤 Для пользователей

- Регистрация и **бесплатный триал** при первом запуске.
- Оплата подписки по **СБП** или **криптовалюте** (TON, ETH, BTC, USDT — TRC20/ERC20/TON/SOL) со скриншотом чека на ручную проверку админом.
- Личный статус подписки: срок действия, ссылка-подписка (Sub Link) для клиента Happ.
- История последних транзакций.
- **Реферальная программа**: за каждые 2 приглашённых друга, активировавших триал, — 14 дней подписки в подарок.
- Гайды по настройке под iOS/Android/Windows/macOS/Linux/AndroidTV.
- Обращение в поддержку прямо из бота — ответ админа приходит туда же.

### 💻 Для администратора

- **Core Control**: статус Docker-контейнера Marzban, uptime, CPU/RAM, версия Xray.
- Выдача, продление и аннулирование подписок по Telegram ID или `@username`.
- Массовая рассылка и массовая выдача дней всем пользователям — **с обязательным подтверждением** перед выполнением.
- Синхронизация базы бота с Marzban в обе стороны, выгрузка активных подписок и событий аналитики в `.xlsx`.
- **Зашифрованные бэкапы** (GPG) баз данных бота и Marzban — в Telegram и на Google Drive.
- Firewall: бан/разбан IP на уровне `iptables`.

## 🏗 Архитектура

```
main.py            — точка входа, регистрация роутеров и фоновых задач
config.py           — вся конфигурация из .env
database.py          — слой доступа к SQLite (aiosqlite), схема и миграции
api_client.py         — клиент Marzban REST API (с пагинацией и авто-обновлением токена)
handlers/
  user.py            — пользовательские сценарии (старт, триал, статус, рефералы, саппорт)
  payment.py           — оплата (СБП/крипта)
  admin.py            — админ-панель и массовые операции
utils/
  notifier.py          — фоновые циклы: истечение подписки, воронки напоминаний, автосинк
  snapshot.py          — ежедневный VACUUM INTO снапшот БД
  screen.py            — единый паттерн отрисовки экрана (edit/delete+resend)
  i18n.py             — базовая мультиязычность (ru/en)
  keyboards.py          — инлайн-клавиатуры
locales/            — тексты интерфейса (ru.json, en.json)
tests/              — pytest (фикстуры на tmp_path SQLite, мок aiohttp/aiosqlite)
```

Бот использует SQLite в режиме **WAL** с `busy_timeout`, чтобы конкурентные запросы не падали с `database is locked`.

## 🚀 Быстрый старт

### Зависимости системы

- Python 3.12+
- `gpg` (GnuPG) — для шифрования бэкапов
- `rclone` — если нужна выгрузка бэкапов на Google Drive (опционально)

### Установка

```bash
git clone https://github.com/emel1ch/tg_vpn.git
cd tg_vpn
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env      # и заполнить своими значениями
python main.py
```

`requirements-dev.txt` уже включает `requirements.txt` — для прод-окружения без тестов/линтера достаточно `pip install -r requirements.txt`.

## ⚙️ Переменные окружения

Полный список — в [`.env.example`](.env.example). Основные группы:

| Группа | Переменные | Назначение |
|---|---|---|
| Telegram | `BOT_TOKEN`, `ADMIN_ID`, `GROUP_ID`, `CHANNEL_ID`, `CHANNEL_URL` | Токен бота, ID админа, группа для чеков/саппорта, канал для обязательной подписки |
| База данных | `DB_NAME`, `BOT_DB_PATH` | Путь к SQLite-файлу бота |
| Marzban | `PANEL_URL`, `PANEL_USER`, `PANEL_PWD`, `MARZBAN_DB_PATH`, `MARZBAN_ENV_PATH`, `HAPP_ROUTING_LINK` | Доступ к панели и путь к её данным на сервере |
| Оплата | `PAYMENT_LINK`, `WALLET_*` | Ссылка на СБП-оплату и адреса крипто-кошельков |
| Бэкапы | `REMOTE_GDRIVE`, `BACKUP_GPG_PASSPHRASE` | Путь rclone-remote и пароль шифрования бэкапов (**обязателен** — без него `/admin` → «Сделать Бэкап» откажет в отправке незашифрованных данных) |
| Гайды | `GUIDE_*` | Ссылки на инструкции по платформам |

Для локальной разработки держите отдельный тестовый `.env` с отдельным тестовым ботом (через [@BotFather](https://t.me/BotFather)) — не гоняйте тесты на боевом токене и боевой базе.

## 📜 Команды администратора

Все команды доступны только `ADMIN_ID`.

| Команда | Аргументы | Описание |
|---|---|---|
| `/admin` | — | Открыть Core Control (статус, статистика, бэкап) |
| `/give_sub` | `<id\|@username> <дни>` | Выдать/продлить подписку |
| `/set_sub` | `<id\|@username> <дни>` | Установить срок ровно N дней от текущего момента |
| `/revoke_sub` | `<id\|@username>` | Аннулировать подписку немедленно |
| `/give_all` | `<дни>` | Выдать N дней всем пользователям (с подтверждением) |
| `/promo_may2` | — | Установить всем срок до фиксированной даты (с подтверждением) |
| `/sendall` | `<текст>` | Массовая рассылка |
| `/sync` | — | Синхронизировать базу бота с Marzban |
| `/export` | — | Выгрузить активные подписки в `.xlsx` |
| `/export_events` | `[дни=30]` | Выгрузить события аналитики за период в `.xlsx` |
| `/ban`, `/unban` | `<IP>` | Управление `iptables` |

Ответ на сообщение с чеком/саппорт-заявкой прямо в группе `GROUP_ID` (реплаем) отправляется пользователю автоматически.

## 🧪 Тесты и CI

```bash
pytest              # юнит-тесты (фикстуры на временной SQLite, без сети)
ruff check .          # линт
```

GitHub Actions (`.github/workflows/ci.yml`) гоняет оба шага на каждый push и pull request. Правила ruff пока намеренно ограничены pyflakes-проверками (`ruff.toml`) — расширение до более строгого набора для legacy-кода запланировано отдельным заходом.

Перед смоук-тестом `python main.py` **обязательно** используйте тестовый `.env` (см. выше) — команды бота пишут в боевые БД/панель Marzban при боевых настройках.

## 🔒 Безопасность

- Все админ-команды и колбэки проверяют `ADMIN_ID`; массовые операции (`/give_all`, `/promo_may2`) требуют явного подтверждения кнопкой.
- Переписка поддержки защищена от подмены ID: получатель ответа определяется по непубличному маркеру в служебном сообщении, а не по тексту, который мог бы вписать пользователь.
- Бэкапы шифруются GPG перед отправкой в Telegram/Google Drive; без `BACKUP_GPG_PASSPHRASE` отправка отменяется.
- SQLite работает в режиме WAL с `busy_timeout` для устойчивости к конкурентным запросам.
- Секреты живут только в `.env` (см. `.gitignore` — `.env`, `.env.*`, кроме `.env.example`) и никогда не коммитятся.

## 📊 Аналитика

Бот пишет события в таблицу `events` (регистрация, активация триала, платежи, напоминания, обращения в поддержку, рефералы и т.д.) и `referral_events` для реферальной программы. Выгрузка — командой `/export_events [дни]`.

Раз в сутки фоновая задача делает `VACUUM INTO` снапшот боевой БД в `snapshots/` — для доступа аналитиков без риска заблокировать прод конкурентными запросами.

## 🌐 Локализация

Базовая инфраструктура i18n (`locales/ru.json`, `locales/en.json`, `utils/i18n.py`) подключена к приветствию и главному меню — язык определяется по `language_code` клиента Telegram с фолбэком на русский. Остальной интерфейс пока на русском и мигрирует в JSON постепенно.

## 📦 Деплой

Бот запускается как `systemd`-сервис:

```ini
[Unit]
Description=GTN VPN Telegram Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/path/to/tg_vpn
ExecStart=/path/to/tg_vpn/venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Обновление: `git pull` → `systemctl restart <service>`. CI/CD-автоматизация деплоя намеренно не подключена — обновления выкатываются вручную, под контролем.
