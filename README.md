# 🛡️ Marzban VPN Telegram Bot

Умный, асинхронный и безопасный Telegram-бот для управления VPN-сервером на базе панели **Marzban (Xray-core)**. Бот обеспечивает полный цикл работы с клиентами: от выдачи ссылок-подписок до приема оплат, а также имеет мощную встроенную панель администратора для управления сервером напрямую из Telegram.

## ✨ Основные возможности

### 💻 Для Администратора (Core Control)
* **Статистика в реальном времени:** Мониторинг загрузки CPU, RAM, аптайма сервера, версии Xray и статуса Docker-контейнера.
* **Управление пользователями:** Выдача и продление подписок прямо в чате по Telegram ID или `@username` (с автоматической синхронизацией с Marzban).
* **Топ пользователей:** Вывод списка активных юзеров и топ-5 по потреблению трафика.
* **Двойной Бэкап:** Безопасное резервное копирование баз данных (Marzban и бота) с одновременной отправкой файлов в Telegram администратору и выгрузкой на Google Drive.
* **Массовая рассылка:** Отправка сообщений всем пользователям с защитой от флуд-лимитов Telegram (anti-spam sleep).
* **Сетевой экран (Firewall):** Бан и разбан IP-адресов злоумышленников на уровне ядра ОС.
* **Поддержка пользователей:** Анонимная пересылка сообщений между юзером и админом.

### 👤 Для Пользователей
* Простая регистрация и получение VPN-настроек в виде универсальной **Sub Link** (ссылки-подписки).
* Удобный профиль (Telegram ID, статус, остаток дней и трафика).
* Команда `/myid` для быстрого получения своего Telegram ID (полезно для пользователей без `@username`).
* Связь с технической поддержкой напрямую через интерфейс бота.

## 📜 Доступные команды


**Пользовательские:**
* `/start` — Зарегистрироваться в системе и открыть главное меню.
* `/myid` — Узнать свой профиль и скопировать Telegram ID.
